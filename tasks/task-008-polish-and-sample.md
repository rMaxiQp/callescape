# Task 008 — Visual polish and sample graph

## Goal

Finish the dark developer-tool UI and provide a meaningful fixture for demos and QA.

## Deliverables

- Complete responsive CSS for a 900×600 minimum viewport: navy shell, slate borders, rounded dark cards, shadows, hover/focus states, and error banner/modal treatment.
- `example.json` containing modified, added, and removed functions; long pseudocode; small exact diffs; ordered/labelled calls; and source-language root comments on both behavior sides.

## Acceptance criteria

- Only individual changed lines are colored; whole comparison panels remain neutral.
- The sample validates and visually exercises sizing, wrapping, edges, statuses, and diff display.
- Error banner is dismissible and centered.
